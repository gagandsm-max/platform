## Core rule

A build unit progresses through:

ARCHITECTURE/CAPABILITY CONTRACT CLOSED → IMPLEMENTED → UNIT TESTED → INTEGRATION TESTED → SECURITY/FAILURE TESTED → BENCHMARKED where relevant → UPGRADE/RECOVERY/OPERABILITY VERIFIED → CERTIFIED

`SPECIFIED != IMPLEMENTED != TESTED != BENCHMARKED != CERTIFIED != DEPLOYED`.

**Monitoring coverage rule:** Technology/family presence in a Mother Reference or Build scope is a coverage/certification TARGET, not an implementation or certification claim. Where applicable, certification is dimensional across Discovery, L1, L2, L3, Topology, NCM, Diagnostics, Security, and version/compatibility. A listed vendor/family is not certification.
