# UI

**Class:** Derived feature brief — non-authoritative
**Primary source:** Platform_09 with supporting Platform_02, 17, 20, 22, 23

## Product objective

Provide an enterprise NOC/admin experience that preserves operational context, exposes evidence and makes safe diagnostics fast without hiding complexity or requiring frequent external-tool context switching.

## Global structure

Typical global surfaces include:

- Home/Overview;
- Observe / domain dashboards;
- Alerts;
- Incidents;
- Topology;
- Flow;
- Logs;
- Inventory/Entities;
- Reports;
- Administration/Settings;
- Notification Center;
- search/command palette;
- user/profile/tenant context.

Navigation and visibility are server-side RBAC/resource scoped.

## Entity detail

Entity pages retain tenant/site/time/filter context and provide domain-specific tabs such as Overview, Metrics, Interfaces, Processes/Services, Logs/Events, Topology/Dependencies, Alerts/Incidents, Changes/NCM, RCA and Audit.

## Troubleshooting

Persistent contextual actions may include:

- Ping;
- Traceroute/Path;
- SNMP Test;
- TCP/DNS/TLS/HTTP test;
- API Test;
- Flow;
- Logs;
- topology;
- configuration;
- CLI;
- Compare;
- Verify Now;
- Live Evidence;
- Investigation Session;
- maintenance.

Browser never opens direct device sockets; actions run through Platform Core/Sensor/Agent control paths.

## Evidence UX

Always distinguish:

- operational status;
- telemetry freshness/quality;
- severity;
- confidence;
- contradictions;
- maintenance/suppression;
- partial-data/source failure.

`No Data`, `Stale`, `Monitoring Degraded` and real failure are visually distinct.

## Large-data UX

Use server-side filtering/pagination/virtualization, bounded queries and appropriate ClickHouse rollups. Top-N/Sankey/Flow/Logs interfaces must guard against unbounded row/edge scans.

## Accessibility and ergonomics

Support readable enterprise density, keyboard navigation where practical, responsive layouts and consistent components. UI is HTTPS-only.

## Errors

Errors expose actionable reason, stable error/correlation ID, retry/diagnostic path and partial-source state. Do not expose secrets or raw stack traces.

## Admin workflows

Guided setup/preflight/preview is preferred for credentials, integrations, log/flow sources, Packs, dashboards and policies. Complex settings should show effective inheritance and estimated capacity impact where applicable.
